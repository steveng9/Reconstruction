# `experiment_scripts/` — what each script is for

This directory accumulated over ~18 months of research. It contains the drivers
that produced every number in the paper, and it is deliberately *not* pruned:
the scripts are the provenance record for `results.db`.

That makes it large, so this file is the map. **Reviewers do not need to run
anything here except the scripts in Tier 1** — see
[`ARTIFACT-APPENDIX.md`](../ARTIFACT-APPENDIX.md) for the evaluated
reproduction path (Experiments 1–4).

## How to read the tables below

Every script is placed in exactly one tier, and each row states what the script
*needs in order to run*:

| Input | Meaning |
|---|---|
| **DB** | Reads `results.db`. Runs offline, in seconds, on a fresh clone. |
| **CSV** | Reads a result CSV. Runs offline **if** that CSV is committed (most are not — see [Result CSVs](#result-csvs)). |
| **RAW** | Re-runs experiments. Needs the real datasets and generated synthetic data (`RECON_DATA_ROOT`); hours to days. |
| **WANDB** | Needs Weights & Biases credentials for *our* project. **Reviewers cannot run these.** |

### Membership inference comparison

`results.db` holds **no MIA rows** — its schema is for reconstruction runs. All
MIA results are committed as CSVs instead, and Table 6 regenerates from them
like every other table:

| File | Contents |
|---|---|
| `mia_comparison_results.csv` | 63 rows behind Table 6 — SynthDistance / NNDR / RA-as-MIA AUC across 3 datasets × 14 SDG configurations, every row tagged with the run it came from |
| `mia_rebuttal_sweep_results.csv` | The DP-generator MIA sweep (AUC, advantage, TPR@FPR=1%) |
| `mia_rebuttal_sweep_adult1k_results.csv` | The same at Adult n=1,000 |
| `raw_logs/` | The console logs those numbers were extracted from — see [`raw_logs/README.md`](raw_logs/README.md) |

The comparison drivers **print** their results rather than writing them, which
is why the logs are the primary source and a parser recovers them.

## Result CSVs

Running the Tier 2/3 scripts scatters timestamped CSVs (`sweep_results_*.csv`,
`linear_sweep_*.csv`, …) into this directory. Historically these were the system
of record; they were migrated into `results.db` in 2026, which is now the source
of truth.

They are gitignored, with the exceptions that the generators read directly and
which are therefore committed. `python reproduce.py --list` prints the same
mapping from its `source` column:

| File | Feeds |
|---|---|
| `quality_results_merged.csv` | Table 2 |
| `ds_risk_scores.csv` | Table 7, $d_s$ column |
| `linear_sweep_adult_1000_20260822_182357.csv` | Table 7 |
| `per_attack_disparity_postrepair.csv` | Table 9 |
| `mia_comparison_results.csv` | Table 6 |

The two `mia_rebuttal_sweep_*.csv` files and `raw_logs/` are committed too.

If you clone this repository you will have exactly these four, which is all
Experiment 1 needs. The rest are working files on the authors' machine; the
results they carry are in `results.db`.
